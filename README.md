# F1 Tracker 2026

**Your personal Formula 1 Race Control dashboard.**

F1 Tracker 2026 is a Windows application developed by **Bytetastic App Productions** that provides Formula 1 standings, race calendar information and desktop race reminders.

## Download

**[Download the latest version](YOUR-GITHUB-RELEASES-LINK)**

1. Open the latest GitHub Release.
2. Scroll down to the **Assets** section.
3. Download `F1 Tracker 2026.exe`.
4. Launch the downloaded application.
5. Welcome to Race Control!

> Always download F1 Tracker 2026 from the official GitHub repository.

## Features

- **Driver Standings** – View the 2026 Formula 1 driver championship standings from Formula1.com.
- **Constructor Standings** – View the 2026 Formula 1 constructor championship standings.
- **Race Calendar** – View the configured 2026 Grand Prix schedule and local start times.
- **Race Notifications** – Receive Windows desktop notifications before a Grand Prix.
- **Multiple Reminder Intervals** – Notifications are scheduled for 30, 10, 5 and 1 minute before race start.
- **Background Monitoring** – Keep the race reminder monitor running in the background.
- **Automatic Startup** – Optionally configure the background monitor to start when you log into Windows.
- **Notification Testing** – Test whether Windows notifications are working.
- **Standings Refresh** – Refresh both driver and constructor standings.

## Race Notifications

F1 Tracker 2026 can send desktop notifications before a scheduled Grand Prix.

| Time Before Race | Reminder |
|---|---|
| 30 minutes | F1 starts in 30 minutes! |
| 10 minutes | F1 starts in 10 minutes! |
| 5 minutes | Five minutes to lights out! |
| 1 minute | The race is about to begin! |

Notifications are displayed through Windows desktop notification pop-ups.

## Background Monitor

The background monitor checks the configured race schedule and sends notifications when reminder times are reached.

There are two ways to start it:

**Start Background Monitor Now**

- Select option 6 from the main menu.
- The background monitor starts immediately.
- Keep the window running for reminders to work.
- Closing the window stops that monitor.

**Enable Background Startup**

- Select option 8 to register a Windows Scheduled Task.
- The monitor is configured to start automatically when you log into Windows.
- Select option 7 to check whether background startup is enabled.
- Select option 9 to disable background startup.

## Driver and Constructor Standings

The application retrieves standings from Formula1.com.

**Driver Standings:** Displays the available driver championship information.

**Constructor Standings:** Displays the available constructor championship information.

**Refresh Both Standings:** Allows you to refresh both standings from the main menu.

An internet connection is required to retrieve the latest information.

## Race Calendar

F1 Tracker 2026 includes a configured 2026 race calendar.

The calendar displays:

- Grand Prix name.
- Race date.
- Local race start time.

The application also identifies the next upcoming race from its configured schedule.

## Requirements
